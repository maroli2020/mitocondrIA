Claude respondeu: Para salvar o MitocôndrIA como favorito permanente no Chrome, a forma mais confiável é hospedar o arquivo online.

Para salvar o MitocôndrIA como favorito permanente no Chrome, a forma mais confiável é hospedar o arquivo online. Aqui estão as duas opções mais simples e gratuitas:

Opção 1 — Netlify Drop (mais fácil, 2 minutos)

  1. Clique nos três pontinhos do artefato → Download para baixar o .html
  2. Acesse drop.netlify.com
  3. Arraste o arquivo para a página
  4. Netlify gera uma URL tipo https://meu-site-abc123.netlify.app
  5. Abra essa URL no Chrome → Ctrl+D para salvar nos favoritos

Opção 2 — GitHub Pages (mais permanente)

  1. Crie uma conta em github.com se não tiver
  2. Crie um repositório novo (ex: mitocondrIA)
  3. Faça upload do arquivo .html renomeado para index.html
  4. Vá em Settings → Pages → Branch: main → Save
  5. Sua URL será https://seu-usuario.github.io/mitocondrIA
  6. Salve nos favoritos normalmente

⚠️ Uma coisa importante sobre a API

O MitocôndrIA faz chamadas à API da Anthropic diretamente do navegador. Quando hospedado externamente, você precisará de uma chave de API (ANTHROPIC_API_KEY) para que os agentes respondam. Posso modificar o código para incluir um campo onde você insere sua chave uma vez por sessão — ela ficaria apenas na memória do navegador, sem ser salva em lugar nenhum. Quer que eu adicione isso?
